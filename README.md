# AnalitikWB — Telegram-бот аналитики Wildberries

Бот команды **PlatSer Group** (корма и товары для животных, цель — №1 в РФ).
Полностью кнопочный интерфейс с эмодзи. Анализ — **только через WB API**.
Никаких ID вводить не надо: бот сам вытаскивает supplier_id из JWT-токена.

## Что разбирает

- 📊 **Продажи** — выручка, чистая выплата, средний чек, возвраты, тренд
- 🔁 **Воронка** — показы → корзина → заказ → выкуп (CR на каждом шаге)
- 🖼 **Контент** — фото, видео, описания, характеристики карточек
- 💰 **Маржа** — комиссии WB и логистика по тарифам
- 📦 **Остатки** — по складам, оборачиваемость, dead/low SKU
- ⭐ **Отзывы и вопросы** — топ болей, без ответа, цитаты
- 🎯 **Стратегия** под бренд PlatSer Group

Каждый блок подкреплён реальными данными из API. Отчёт пишет **GPT-5**
с HTML-разметкой: заголовки, цитаты, выделения — никакой стены текста.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# заполнить TELEGRAM_BOT_TOKEN и OPENAI_API_KEY

python bot.py
```

В Telegram открой бота → `/start` → жми **🔑 Подключить WB API**.
Дальше бот сам подскажет какие галочки поставить в кабинете WB и
куда вставить токен.

## Как создать WB-токен (бот покажет в чате при подключении)

1. [Кабинет WB → Настройки → Доступ к API](https://seller.wildberries.ru/supplier-settings/access-to-api).
2. *Создать новый токен*, название любое (например `AnalitikWB`).
3. Срок жизни — **180 дней**.
4. Отметь категории:
   - ✅ **Контент** — карточки, фото, описания
   - ✅ **Аналитика** — воронка показы→корзина→заказ→выкуп *(нужна подписка Аналитика Pro)*
   - ✅ **Статистика** — продажи, заказы, остатки
   - ✅ **Тарифы** — комиссии WB и логистика
   - ✅ **Вопросы и отзывы** *(опционально)*
5. *Только для чтения* — можно оставить включённым, бот ничего не пишет.
6. Скопируй токен (длинная строка `xxx.yyy.zzz`) и отправь в чат боту.

Если какого-то скоупа в токене нет — конкретный блок будет помечен
«нет данных», остальное продолжит работать.

## Переменные окружения (`.env`)

| Переменная | Назначение | Обязательная |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather | ✅ |
| `OPENAI_API_KEY` | ключ OpenAI | ✅ |
| `OPENAI_MODEL` | модель (по умолчанию `gpt-5`) | — |
| `WB_TOP_PRODUCTS` | сколько товаров брать (30) | — |
| `WB_REVIEWS_PER_PRODUCT` | отзывов на товар (30) | — |
| `WB_DEST` | регион dest для WB API | — |
| `WB_STATS_DAYS` | период продаж по умолчанию (30) | — |
| `WB_SUPPLIER_TOKEN` | WB-токен по умолчанию — авто-подключение при `/start` | — |

`WB_SUPPLIER_TOKEN` опционален: если задан — бот при `/start` сразу
авторизуется этим токеном, в чат вводить не нужно. Если пуст — бот
попросит токен у пользователя.

## Безопасность токена

- Введённый токен хранится **только в памяти процесса** (FSM MemoryStorage).
  При перезапуске бота — пропадает.
- Сообщение с токеном **удаляется из чата** сразу после проверки.
- Бот делает только GET-запросы к WB API. Ничего не пишет, не меняет цены,
  не редактирует карточки.

## Архитектура

```
bot.py        — aiogram-бот, FSM, инлайн-кнопки, обработка токена
keyboards.py  — клавиатуры с эмодзи
wb_api.py     — WBClient (public) + WBAuthClient → Stats/Content/Analytics/Common
analyzer.py   — агрегации: продажи, воронка, контент, маржа, остатки, отзывы, Q&A
gpt.py        — промпт под PlatSer + 8 режимов разбора в HTML
config.py     — настройки из .env
```

## Замечания

- Используем 5 разных WB API + публичные эндпоинты feedbacks/questions.
- ChatGPT работает по сводке (агрегаты), а не по сырым строкам — расход
  токенов разумный.
- Воронка (`/api/v2/nm-report/detail`) требует подписку **Аналитика Pro**
  в WB-кабинете. Без неё бот вернёт «нет funnel» — остальные блоки работают.
