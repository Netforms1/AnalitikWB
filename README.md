# AnalitikWB — Telegram-бот аналитики Wildberries

Бот команды **PlatSer Group** (корма и товары для животных, цель — №1 в РФ).
Полностью кнопочный интерфейс с эмодзи. Собирает публичные данные WB
по продавцу и через **ChatGPT API** выдаёт развёрнутый разбор:

- 📈 спрос и потенциал, тренд (рост / падение / стагнация)
- 💰 ценовая политика — можно ли поднять цену по сигналам продаж
- 📦 ассортимент и слабые карточки (что добавить, убрать, переснять)
- ⭐ боли клиентов из отзывов (топ-негативные термины + цитаты)
- 🎯 стратегические рекомендации под бренд PlatSer Group

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# в .env заполнить TELEGRAM_BOT_TOKEN и OPENAI_API_KEY

python bot.py
```

## Что нужно для запуска

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `OPENAI_API_KEY` | ключ OpenAI |
| `OPENAI_MODEL` | модель (по умолчанию `gpt-4o-mini`) |
| `WB_TOP_PRODUCTS` | сколько товаров продавца брать (по умолчанию 30) |
| `WB_REVIEWS_PER_PRODUCT` | отзывов на товар (по умолчанию 30) |
| `WB_DEST` | регион dest для WB API (по умолчанию Москва) |

## Как пользоваться

1. В Telegram: `/start`.
2. Жми кнопку — например, **🔍 Анализ магазина**.
3. Пришли *ID продавца WB* — это число из URL `wildberries.ru/seller/<ID>`.
4. Выбери режим:
   - 🚀 *Полный разбор* — все блоки
   - 💰 *Цены* — можно/нельзя поднять
   - ⭐ *Отзывы* — боли и быстрые победы
   - 📦 *Ассортимент* — пробелы и слабые карточки
   - 📈 *Спрос* — где OOS-риск и где переоценка
   - 🎯 *Совет под PlatSer* — стратегия к №1 в РФ
5. Получаешь Markdown-отчёт прямо в чат + кнопки для повтора / нового магазина.

## Архитектура

```
bot.py         — aiogram-бот, инлайн-кнопки, FSM
keyboards.py   — все клавиатуры с эмодзи
wb_api.py      — асинхронный клиент к WB (catalog / card / feedbacks)
analyzer.py    — агрегация: цены, рейтинги, OOS, частотный анализ отзывов
gpt.py         — промпт под PlatSer Group + режимы анализа
config.py      — настройки из .env
```

## Глубокая аналитика своего магазина (PlatSer Group)

Если в `.env` заданы `WB_SUPPLIER_TOKEN` (с расширенными скоупами) и
`WB_OWN_SUPPLIER_ID`, бот автоматически подтянет данные из **5 разных WB API**
и подмешает их в JSON для ChatGPT.

| API | Что забираем | Скоуп в WB-кабинете |
|---|---|---|
| Statistics | продажи, заказы, остатки, возвраты, средний чек | Статистика |
| Content | карточки, фото, видео, описания, характеристики | Контент |
| Analytics | воронка opens→cart→order→buyout по SKU | Аналитика (Pro) |
| Common | комиссии WB и логистика коробов → реальная маржа | Тарифы |
| Public Q&A | вопросы клиентов, доля без ответа | (без токена) |

Как настроить:
1. WB-кабинет → *Настройки → Доступ к API → Создать токен*.
2. Отметь категории: **Статистика, Контент, Аналитика, Тарифы**. Срок — 180 дней.
3. Скопируй JWT в `WB_SUPPLIER_TOKEN`, ID PlatSer-магазина — в `WB_OWN_SUPPLIER_ID`.

Бот ничего не пишет в WB — только чтение. Если какого-то скоупа нет —
конкретный блок будет помечен «нет доступа», остальное продолжит работать.

## Модели OpenAI

По умолчанию используется `gpt-5`. Можно переключить в `.env` на
`gpt-5-mini` (дешевле/быстрее) или `gpt-4o-mini` (старая модель).
Для `gpt-5` и o-серии параметр `temperature` не передаётся (эти модели
его не принимают) — бот это делает автоматически.

## Замечания

- Используются только **публичные** эндпоинты WB для анализа любого
  магазина + **Statistics API** для собственного. Лимиты и схема могут
  меняться — клиент устойчив к 5xx и 429.
- ChatGPT работает по сводке (а не по сырым отзывам построчно), чтобы
  держать расход токенов разумным. Размеры выборок настраиваются.
